# Library Management System

## 📚 Giới thiệu

Library Management System là hệ thống quản lý thư viện được xây dựng bằng **Spring Boot** nhằm tối ưu hóa quy trình mượn/trả sách, quản lý danh mục sách, người dùng, và cung cấp các chức năng như tìm kiếm sách, gửi thông báo quá hạn qua email, báo cáo thống kê.

## ⚙️ Công nghệ sử dụng

- **Backend:** Spring Boot, Spring Data JPA, Spring Security
- **Cơ sở dữ liệu:** MySQL
- **API:** RESTful
- **Quản lý phụ thuộc:** Maven
- **Giao diện người dùng:** Không có (API backend)
